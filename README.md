# Satisfaculty

> **Satisfaculty is moving to the browser.** [satisfaculty.com](https://satisfaculty.com) now hosts the new
> in-browser tool ([satisfaculty-js](https://github.com/zsunberg/satisfaculty-js)), starting with teaching
> assignments; course scheduling will follow and replace this Python package. Until then this package still
> works, and its documentation has moved to <https://zachary.sunberg.net/satisfaculty/>.

A python course scheduling optimization tool that uses integer linear programming.

## Installation

```bash
pip install satisfaculty
```

For the latest development version:

```bash
pip install git+https://github.com/zsunberg/satisfaculty.git
```

## Documentation

See the [full documentation](https://zsunberg.github.io/satisfaculty/) for usage, examples, and the objectives guide.
